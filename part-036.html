Membuat Tabel di Supabase
Sekali saja — tidak perlu impor CSV
Skrip di bawah sudah tersalin otomatis. Anda tinggal menempelkannya di Supabase. Skrip ini hanya membuat wadah kosong — produk Anda akan terisi sendiri saat sinkronisasi berjalan.
Langkah
  1. Klik Buka SQL Editor di bawah — tab Supabase terbuka
  2. Klik area kosong pada editor, tekan Ctrl+V untuk menempel
  3. Klik tombol Run (atau tekan Ctrl+Enter)
  4. Pastikan muncul tulisan Success di bawah editor
  5. Kembali ke sini, tutup jendela ini
  6. Centang Aktifkan sinkronisasi katalog
Klik kotak untuk memilih seluruh teks. Aman dijalankan berulang — memakai if not exists.
Bukan impor CSV. Menu Table Editor → Import di Supabase tidak dipakai di sini. Tabel ini harus dibuat lewat SQL agar kolom dan izin aksesnya persis sesuai kebutuhan aplikasi.

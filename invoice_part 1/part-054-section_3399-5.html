Isi hanya alamat dasarnya — tanpa /rest/v1 atau path lain. Temukan di Project Settings → API → Project URL.
Bukan alamat web. Diawali sb_publishable_ (format baru) atau eyJ (format lama). Ambil dari Project Settings → API Keys. Jangan memakai service_role / sb_secret_.
Khusus berkas backup — isi invoice-backup. Bucket produk-gambar belum dipakai; itu untuk gambar produk di tahap berikutnya.
Kode perangkat disisipkan ke nomor invoice (mis. INV-20260829-A005) agar dua perangkat tidak membuat nomor kembar. Kosongkan bila hanya memakai satu perangkat.
Cara menyiapkan Supabase (klik) 
1. Buat project di supabase.com (gratis)
2. Storage > New bucket > nama: invoice-backup
   Public bucket: NONAKTIF
3. Settings > API > salin "Project URL" dan "anon public"
4. SQL Editor, jalankan policy berikut:

create policy "backup rw"
on storage.objects for all
to anon
using   ( bucket_id = 'invoice-backup' )
with check ( bucket_id = 'invoice-backup' );
Anon key memang aman dipublikasikan selama akses dibatasi lewat policy di atas. Untuk keamanan lebih ketat, gunakan bucket khusus yang hanya menyimpan backup.
